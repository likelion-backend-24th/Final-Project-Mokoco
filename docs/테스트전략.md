## Test 전략 요약

Mokoco의 Test는 다음 위험을 중심으로 구성되어 있어요(실제 테스트 코드에서 확인).

- **인증**: JWT에서 검증된 `userId`만 사용자 신원으로 신뢰한다 (`JwtUserIdTest`).
- **서비스 간 내부 인증**: `X-Internal-Service-Key` 없이는 내부 API를 호출할 수 없다 (`InternalServiceSecurityTest`, `UserClientConfigTest`).
- **권한/소유권**: 참여자가 아닌 사용자의 채팅방·계약·제안 접근을 차단한다 (`ChatServiceTest`, `ChatRoomOrchestrationServiceTest`, `ChatAttachmentTest`, `ContractServiceTest`, `ProposalServiceTest`).
- **동시성/멱등성**: 동시 접근·중복 요청에도 자원 한도를 넘기지 않는다 (`AiPostDraftRepositoryTest`의 재작성 횟수 원자적 차감).
- **DB 일관성**: 취소 후 재매칭처럼 "한 postId에 여러 행"이 남는 케이스를 단순 조회가 못 견디는 문제를 실제 MySQL로 검증한다 (`FixDealRepositoryTest`).
- **Schema 일치**: Flyway 마이그레이션이 빈 MySQL DB에서 끝까지 실행되고 Entity와 Schema가 `ddl-auto=validate`를 통과한다 (`FlywaySchemaTest`, 4개 서비스 공통).
- **파일 업로드 안전성**: 확장자가 아니라 실제 파일 바이트로 이미지/영상 타입을 판별해 위장 업로드를 막는다 (`ChatAttachmentTest`).
- **AI 응답 신뢰 경계**: 금액 등 핵심 거래값은 AI 응답이 아니라 서버 값으로 고정한다 (계약 AI 관련, `ContractServiceTest`의 결제 게이팅과 연결).

## 전체 회귀 실행

각 서비스 CI(`.github/workflows/ci-*.yml`)가 해당 서비스 경로 변경 시 push/PR마다 실행돼요. 이번 세션에서는 아래처럼 실제 MySQL 8.0 컨테이너(CI와 동일한 환경변수)로 반복 검증했어요.

```bash
docker run -d --name ci-verify-mysql -e MYSQL_ROOT_PASSWORD=root1234 -e MYSQL_DATABASE=<db> -p 3306:3306 mysql:8.0
# 서비스별 CI 워크플로의 환경변수를 그대로 넣고
./gradlew clean test --no-daemon
```

- post-service: 46개 테스트 전체 통과 (2026-09-29 기준, `ProposalServiceTest` 추가 후)
- payment-service: 전체 통과
- user-service: `application-secret.yml` 부재 문제 수정 후 전체 통과 (`577866b`)

Frontend는 `npm run lint && npm run build`로 검증(경고 9개는 기존부터 있던 것, 에러 없음).

## Sprint Demo 시나리오 (정상 흐름)

Actor: 의뢰자 A, 수리자 B — 둘 다 가입·로그인·활동지역 설정 완료.

1. A가 수리 요청 게시글 등록 (`POST /posts`) → B가 견적 제안 (`POST /posts/{postId}/proposals`)
2. A가 B의 제안 채택 (`PATCH .../adopt`) → `FixDeal` 생성, 게시글 `MATCHED`
3. 채팅방 생성 (`POST /api/chat-rooms/fix-deals/{fixDealId}`), 메시지 송수신(WebSocket)
4. 계약서 작성·서명 (`POST /api/chat-rooms/{roomId}/contract`, `.../sign`)
5. 결제 (`POST /payments/prepare` → PortOne → `POST /payments`)
6. 작업 시작(`start`, 결제 완료 확인) → 완료 신청(`finish`) → 완료 확정(`accept`, 정산 확정)
7. 후기 작성 (`POST /reviews`)

**관련 Test**: `ProposalServiceTest`, `ChatRoomOrchestrationServiceTest`, `ChatServiceTest`, `ContractServiceTest`, `FixDealRepositoryTest`
