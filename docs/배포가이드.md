## 사전 조건과 환경 변수

| 항목 | 요구 Version·값 | 확인 명령 | 공개 가능 여부 |
|---|---|---|---|
| JDK·Runtime | Java 21 (Gradle toolchain, Spring Boot 3.4.2) | `java -version` | 가능 |
| Docker Compose | v2 문법 (compose 파일 최상위 `version` 필드 없음) | `docker compose version` | 가능 |
| Secret | `application-secret.yaml`/`.yml`, `.env` (모두 gitignore) — 이름만 아래 참고, 실제 값은 팀 채널 공유 | `find backend -iname 'application-secret.y*ml'` | 실제 값 금지 |

### 새 clone 실행

```bash
cp backend/user-service/src/main/resources/application-secret.yaml.example backend/user-service/src/main/resources/application-secret.yaml
cp backend/payment-service/src/main/resources/application-secret.yaml.example backend/payment-service/src/main/resources/application-secret.yaml
cp backend/post-service/.env.example backend/post-service/.env
cp frontend/.env.example frontend/.env
# 위 4개 파일에 실제 시크릿 값 채워넣기 (팀 채널 공유, git 커밋 금지)
docker compose config
docker compose up -d --build
```
