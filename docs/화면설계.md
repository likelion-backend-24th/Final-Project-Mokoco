# 화면설계

## Sprint 1(회원가입 및 로그인, CRUD)

| 화면 | Actor·행동 | 입력 | 성공 표시 | 실패 표시·다음 행동 | 호출 계약 |
| --- | --- | --- | --- | --- | --- |
| 회원가입 | 유저 - 회원정보 입력 | 이름, 닉네임, 이메일, 비밀번호 | 회원가입 성공 알림 | 중복 이메일·닉네임 409 | signUp — POST /api/auth/signup |
| 로그인 | 유저 - 로그인 정보 입력 | 이메일, 비밀번호 (Kakao OAuth 가능) | 로그인된 상태로 홈으로 이동 | 존재하지 않는 이메일·잘못된 비밀번호 401 | signIn — POST /api/auth/signin |
| 활동 지역 설정 | 유저 - GPS 좌표 전달 또는 지도에서 직접 선택 | 위도·경도(Kakao Local API로 행정구역 변환, 좌표 자체는 저장 안 함) | 내 활동 지역으로 저장 완료 | 위치 권한 거부 시 지도에서 수동 선택으로 대체 | updateRegion/getRegion — PATCH·GET /api/users/me/region |
| 게시글 작성 | 유저 - 게시글 정보 입력 | 제목, 내용, **카테고리**, 사진(선택, 최대 여러 장) | 작성 완료 → 상세 화면 이동 | 인증 없음 401, 필수값 누락 400 | createPost — POST /api/posts (multipart) — **지역은 입력값이 아니라 작성자의 활동 지역에서 서버가 자동으로 채움** |
| 게시글 목록 | 유저/게스트 - 페이지 진입 | 카테고리(선택), **지역 범위**(전체/시도/시군구/동), 페이지 | 게시글 목록 출력 | 결과 없음(빈 목록) | listPosts — GET /api/posts — **키워드 검색·날짜 필터는 실제로 없음** |
| 게시글 상세 | 유저/게스트 - 게시글 상세 조회 | postId | 게시글 내용, 작성자, 사진, **받은 제안 목록** | 존재하지 않는 게시글 → 404 | getPost — GET /api/posts/{id} — **가격·댓글 필드는 게시글에 없음(가격은 제안 단계에만 존재, 댓글 기능 자체가 없음)** |
| 게시글 수정 | 게시글 작성자 - 수정 | 제목, 내용, 카테고리 | 수정 완료 → 상세 화면 갱신 | 권한 없음 403, 게시글 없음 404 | updatePost — PATCH /api/posts/{id} — 사진 추가/삭제는 별도 API(`POST/DELETE .../images`) |
| 게시글 삭제 | 게시글 작성자/관리자 - 삭제 | postId | 삭제 완료 → 목록 이동 | 권한 없음 403, 없음 404 | deletePost — DELETE /api/posts/{id} |

## Sprint 2(제안·채팅·계약)

| 화면 | Actor·행동 | 입력 | 성공 표시 | 실패 표시·다음 행동 | 호출 계약 |
| --- | --- | --- | --- | --- | --- |
| 수리 제안 등록 | 수리자 - 견적·설명 입력 | 희망 견적, 제안 내용, **이력서 공개 여부(선택, attachResume)** | 제안 등록 완료 → 상세 갱신 | 마감된 글에 제안 시 409 | createProposal — POST /api/posts/{postId}/proposals |
| 수리 제안 목록 | 의뢰자/수리자 - 게시글 상세 진입 | postId | 제안 목록(견적·내용·이력서 보기 버튼) 출력 | 결과 없음 | listProposals — GET /api/posts/{postId}/proposals |
| 수리 제안 채택 | 의뢰자 - 제안 선택 | proposalId | 채택 완료 → 계약서 작성으로 안내 | 작성자 아님 403, 이미 채택된 요청 409 | adoptProposal — PATCH /api/posts/{postId}/proposals/{proposalId}/adopt |
| 수리 제안 취소 | 제안자 - 제안 철회 | proposalId | 삭제 완료 → 목록 갱신 | 채택됨/채팅방 있음 409 | deleteProposal — DELETE /api/posts/{postId}/proposals/{proposalId} |
| 채팅방 개설·목록 | 의뢰자/수리자 - 채팅 진입 | proposalId(채택 전) 또는 fixDealId(채택 후) | 채팅방 생성 또는 기존 채팅방 이동 | 참여자 아님 403 | createForProposal/createChatRoom — POST /api/chat-rooms/proposals/{id} 또는 /fix-deals/{id} — **채택 전 제안 단계부터 채팅 가능(문서에 없던 흐름)** |
| 채팅 메시지 송수신 | 채팅방 참여자 - 메시지 입력·전송 | 텍스트 또는 첨부파일 | 메시지 실시간 표시 | 참여자 아님, 채팅방 없음 | STOMP SEND /app/chat/{roomId}, 첨부 POST /api/chat-rooms/{roomId}/attachments |
| 수리 계약서 작성 | 거래 당사자 - 계약 조건 입력(AI 초안 도움 가능) | 작업범위, 금액, 지급조건, 시작·완료일 등 | 계약서 초안(DRAFT) 생성 | 당사자 아님 403 | POST /api/chat-rooms/{roomId}/contract |
| 수리 계약서 서명 | 거래 당사자 - 서명 확인 | consent | 서명 완료 → 양측 서명 시 SIGNED | 이미 서명 시도 409 | POST /api/chat-rooms/{roomId}/contract/sign |

## Sprint 3(결제·후기·이력서·프로필·신고·관리자·AI)

| 화면 | Actor·행동 | 입력 | 성공 표시 | 실패 표시·다음 행동 | 호출 계약 |
| --- | --- | --- | --- | --- | --- |
| 안전결제(에스크로) | 의뢰자 - 서명 완료 직후 PortOne 결제창 진행 | 결제 수단 | 결제 완료 → 대금은 거래 완료까지 회사가 보관 | 계약 미서명 상태 409, 중복 결제 409, PortOne 장애 502 | createPayment — POST /api/payments — **과거엔 "완료 신청 이후"였으나 계약 서명 직후로 변경됨** |
| 작업 시작 | 수리자 - 시작 처리 | roomId, action=start | 거래 상태 REPAIRING으로 전환 | **결제 미완료 시 409**, 수리자 아님 403 | POST /api/chat-rooms/{roomId}/contract/start |
| 완료 신청 | 수리자 - 완료 신청 | roomId, action=finish | 거래 상태 REPAIR_DONE으로 전환 | 상태 불일치(REPAIRING 아님) 409 | POST /api/chat-rooms/{roomId}/contract/finish |
| 완료 확정 | **의뢰자** - 완료 확인 | roomId, action=accept | 거래 상태 COMPLETED, **정산 확정(settle)** | 의뢰자 아님 403, 상태 불일치 409 | POST /api/chat-rooms/{roomId}/contract/accept |
| 정산 내역 조회 | 수리자 - 정산 확인 | 없음(로그인) | 내가 받은 정산 목록·합계 표시 | 인증 없음 401 | GET /api/payments/mine |
| 후기 작성 | 거래 당사자 - 완료된 거래에 후기 작성 | 별점, 내용, 사진(선택) | 작성 완료 | 미완료 거래 409, 중복 후기 409 | createReview — POST /api/reviews (multipart) |
| 후기 조회 | 누구나 - 특정 유저 받은 후기 확인 | revieweeEmail | 별점·후기 목록 표시(공개) | 없음(빈 목록) | GET /api/reviews?revieweeEmail= |
| 이력서 작성·수정 | 수리자 - 이력서 작성 | 한 줄 소개, 전문 분야, 경력, 자기소개 | 저장 완료 | 인증 없음 401 | POST/PATCH /api/resume |
| 이력서 조회 | 누구나 - 특정 수리자 이력서 확인 | email | 이력서 내용 표시(공개) | 이력서 없음 404 | GET /api/resume/{email} |
| 내 프로필 | 유저 - 거래 내역·후기 확인 | 없음(로그인) | 의뢰자/수리자 거래 내역, 작성/받은 후기 탭 | 인증 없음 401 | GET /api/profile/transactions, /api/profile/reviews |
| 수리자 정보 팝오버 | 유저 - 제안 목록에서 수리자 이메일 클릭 | repairerEmail | "거래 내역 보기"/"신고하기" 메뉴 | - | GET /api/profile/{email}/transactions(공개) |
| 신고 접수 | 유저 - 글/유저 신고 | 대상, 사유, 상세 내용(선택) | 접수 완료 안내 | 인증 없음 401 | POST /api/reports |
| 관리자 - 신고 처리 | Admin - 신고 목록 확인·처리 | reportId | 해결/기각 처리 | Admin 아님 403 | GET /api/admin/reports, PATCH .../resolve·dismiss |
| 관리자 - 유저 관리 | Admin - 권한·정지 관리 | userId | 역할 변경/정지 완료 | Admin 아님 403 | GET /api/admin/users, PATCH .../role·status |
| 관리자 - 글 강제 삭제 | Admin - 작성자 무관 삭제 | postId | 삭제 완료 | Admin 아님 403 | DELETE /api/admin/posts/{id} |
| AI 게시글 작성 도움 | 유저 - 사진 업로드 후 초안 요청 | 사진 1~5장, 현재 입력값(선택) | 제목·내용·카테고리 자동 채움(수정 가능) | AI 비활성화 503, 한도초과 429 | POST /api/ai/post-draft |
| AI 계약서 초안 | 거래 당사자 - 채팅 기반 초안 요청 | 추가 요청사항(선택) | 계약 항목 자동 채움(근거 표시, 금액·날짜는 서버가 고정값 사용) | 상태 불일치 409, AI 실패 502/503 | POST /api/chat-rooms/{roomId}/contract/ai-draft |
